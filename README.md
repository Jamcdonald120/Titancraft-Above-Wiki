# Titancraft-Above-Wiki

The wiki for the Above on Titancraft, Tangotek's private patreon minecraft server [https://www.patreon.com/tangotek](https://www.patreon.com/tangotek)


This wiki is built using [Docusaurus](https://docusaurus.io/), a modern static website generator. You can find out how to use Markdown in [the Docusaurus docs](https://docusaurus.io/docs/markdown-features).

## Installation

```bash
npm
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.
