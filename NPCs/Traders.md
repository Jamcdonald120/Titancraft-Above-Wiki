# Wandering Traders

There are a number of traders wandering around the Above that players may encounter. Each trader stocks a different type of item and will appear in different places on different days. Setting up camp in a new location each ingame morning, and shutting up shop (disappearing) in the evening. Generally speaking, traders want [Titanshard Gems](../Loot#gems) in exchange for their goods.
