## Science!

Listed below are the actual results from the "transformational" enchantments that were introduced in the above. If you perform ***Science!*** and learn new results not included here, please let us know so we can list them!

### Bleach

Removes any Dye color from the blocks (Dyed Terracotta to normal Terracotta, Dyed Wool to White Wool etc.)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Coloured Terracotta | Terracotta |
| Coloured Concrete | White Concrete |
| Coloured Shulker Box | Shulker Box |
| Axe |     |     |
| Shovel | Coloured Concrete Powder | White Concrete Powder |
| Shears | Coloured Wool | White Wool |

### Chisel

Changes blocks into the cut variety (Sandstone to Cut Sandstone, Quartz to Quartz brick, Nether brick to Chiseled nether brick)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Sandstone | Cut Sandstone |
| ^^  | Quartz Block | Quartz Brick |
| ^^  | Nether Brick | Chiseled Nether Brick |

### Extract

Extracts components from blocks (Granite or Diorite give Quartz, Andesite gives Diorite)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Andesite | Diorite |
| ^^  | Granite | Quartz |
| ^^  | Diorite | Quartz |
| ^^  | Coloured Concrete | Dye |
| ^^  | Stained Glass | Dye |
| Axe |     |     |
| Shovel | Concrete Powder | Dye |
| ^^  | Rooted Dirt | Hanging Roots |
| ^^  | Grass | Short Grass |
| Shears | Coloured Wool | Dye |

### Forge

Transforms broken blocks as if they had been cooked in a furnace

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Stone (Silk Touch) | Smooth Stone |
| ^^  | Stone | Stone |
| ^^  | Stone Bricks | Cracked Stone Bricks |
| Shovel | Sand | Glass |
| Hoe | Potato | Baked Potato |
| ^^  | Kelp | Dried Kelp |
| ^^  | Wet Sponge | Dry Sponge |

### Green Thumb

Changes blocks into a "green" variety (Dirt to Rooted Dirt, Grass to Moss etc.)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Cobblestone | Mossy Cobblestone |
| ^^  | Stone Bricks | Mossy Stone Bricks |
| Shovel | Dirt | Rooted Dirt |
| ^^  | Grass | Moss |
| ^^  | Mud | Muddy Mangrove Roots |
| Hoe | Big Dripleaf | Small Dripleaf |
| Axe | Big Dripleaf | Small Dripleaf |

### Hydrate

Changes blocks into the "wet" version (Dirt to Mud etc.)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Terracotta | Clay |
| ^^  | Dead Coral | Coral |
| Shovel | Concrete Powder | Concrete |
| ^^  | Dirt | Mud |
| Hoe | Dry Sponge | Wet Sponge |
| Shears | Grass | Sea Grass |
| ^^  | Ferns | Kelp |

### Philia

Converts any item in the target materials family into the target material. (ie: Philia: Oak would turn any wood or leaf item into its Oak equivalent; Philia: Blackstone would turn any stone into its Blackstone equivalent)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe |     |     |
| Axe |     |     |
| Hoe |     |     |
| Shears |     |     |
| Shovel |     |     |

### Pulverize

Breaks down a block into the next "finer" block (gravel into sand, for example)

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Pickaxe | Cobblestone | Gravel |
| ^^  | Quartz Block | Quartz |
| ^^  | Sandstone | Sand |
| ^^  | Red Sandstone | Red Sand |
| Shovel | Gravel | Sand |
| Hoe | Nether Wart Block | Nether Wart |
| Axe | Wood | Planks |
| Shears | Wool | String |

### Void

If a weapon with Void kills a mob, it drops no loot or XP. Same for any blocks mined.

| Tool | Target Block | Resulting Block |
| --- | --- | --- |
| Any tool | Any block | Nothing |
